What is the Master Set?

The Master Set is a collection of cards, specifically every version of a card. While there are many variations on a master set, some including cameos, I will be doing my own, if you want my source for most of this list it can be found here and it should include most all cards.

What does your master set include?

My master set incudes the following:

  • Standard
  • Holo/Glossy
  • Reverse Holo
  • Reprints
  • Stamps (and Codes)
  • Promos
  • Alt Arts
and excludes the following:
  • Misprints (too many)
  • Alt Languages (English is fine thanks)
  • Cameos (I'm already going broke I don't need more debt)
